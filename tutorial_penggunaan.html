Google Scholar Scraper

Panduan Penggunaan

Petunjuk praktis menjalankan aplikasi dan mengunduh data publikasi dosen ke Microsoft Excel.

1
Membuka Aplikasi

Buka folder aplikasi di komputer Anda, lalu klik dua kali (double-click) berkas peluncur yang sesuai:

Pengguna Mac
run_mac.command
Klik 2x berkas ini. Browser akan otomatis terbuka.
Pengguna Windows
run_windows.bat
Klik 2x berkas ini. Browser akan otomatis terbuka.
Aplikasi web akan otomatis terbuka di browser pada alamat http://localhost:8501. Semua kebutuhan program akan disiapkan secara otomatis tanpa perlu instalasi manual.
2
Mengisi Parameter & Memulai
  • ID Author atau Link Profil: Buka profil Google Scholar dosen target, lalu salin alamat URL atau kode ID author-nya:
    https://scholar.google.com/citations?user=K_X8HzoAAAAJ&hl=en
  • Tahun Mulai & Tahun Akhir: Tentukan periode waktu sitasi dan artikel yang ingin direkap (misal: 2023 hingga 2026).
  • Kecepatan Scraping: Gunakan pilihan Santai / Aman untuk stabilitas pengambilan data yang optimal.
  • Batas Artikel (Opsional): Biarkan 0 untuk mengambil semua artikel, atau isi angka (misal: 5) jika hanya ingin pengujian singkat.
  • Klik Tombol Mulai: Tekan tombol hijau Mulai. Jendela Google Chrome akan terbuka dan proses ekstraksi langsung berjalan.
3
Jika Muncul Verifikasi Robot (CAPTCHA)

Google terkadang menampilkan verifikasi robot untuk memastikan keamanan akses:

  • Jika di dashboard muncul kotak peringatan kuning, buka jendela Google Chrome yang sedang berjalan di komputer Anda.
  • Centang kotak "I am not a robot" atau selesaikan verifikasi gambar di Chrome.
  • Setelah selesai, sistem akan otomatis melanjutkan proses scraping tanpa perlu menekan tombol apa pun.
4
Membuka Hasil & Analisis
  • Berkas Excel Otomatis Tersimpan: Seluruh data disimpan rapi di dalam folder hasil_scraping/ dengan format .xlsx (Microsoft Excel).
  • Tombol Buka Hasil: Klik tombol hijau Buka Hasil untuk langsung membuka folder penyimpanan di komputer Anda.
  • Tab Analisis: Buka tab Analisis di bagian atas untuk melihat grafik peran penulis, sebaran jurnal nasional/internasional, dan tren sitasi tahunan.
  • Tab Riwayat Berkas: Buka tab Riwayat Berkas untuk melihat daftar seluruh berkas Excel yang pernah dibuat sebelumnya.
?
Pertanyaan yang Sering Diajukan
Apakah proses bisa dilanjutkan jika sempat terhenti? +
Bisa. Aplikasi memiliki fitur simpan otomatis (checkpoint). Jika Anda menjalankan ulang dengan ID author dan rentang tahun yang sama, artikel yang sudah tersimpan akan otomatis dilewati.
Bagaimana cara memperbarui data peringkat Scopus? +
Cukup masukkan berkas SCImagoJR terbaru (misalnya scimagojr 2026.csv) ke dalam folder data/. Sistem akan otomatis mendeteksi dan menggunakan berkas tahun terbaru sebagai acuan kuartil Scopus.
Bagaimana cara menutup aplikasi setelah selesai? +
Tutup tab browser Anda, lalu pada jendela Terminal atau Command Prompt yang terbuka, tekan tombol Ctrl + C di keyboard untuk menghentikan program.
